## step2
色々と調べてみると、x が大きかった場合（2,147,447,412 < x の32-bit符号付き整数）は、言語によっては Overflow を起こすらしい
→ python の場合は, int は多倍長整数を採用しているので、自動的にメモリーが拡張されるらしい
→ 数値の後半半分のみを反転させて、前半部分と比較する

また、末尾が0の場合も、「-」と同様、Falseになる
